# 🏦 BankAdvisr

C'est une application complète pour gérer les relations entre consultants bancaires et clients.

## ✨ Ce que l'app peut faire :
- **Suivi de projet** : Voir l'avancement des dossiers (0% à 100%).
- **Documents** : Envoyer et recevoir des fichiers de manière sécurisée.
- **Rendez-vous** : Un calendrier pour réserver des créneaux facilement.
- **Nettoyage auto** : Quand on supprime un projet, le serveur efface aussi les fichiers pour ne pas gaspiller d'espace.

## 🛠️ Les outils utilisés :
- **Façade (Front)** : React.js
- **Moteur (Back)** : Java Spring Boot
- **Mémoire (Base de données)** : Firebase Firestore
